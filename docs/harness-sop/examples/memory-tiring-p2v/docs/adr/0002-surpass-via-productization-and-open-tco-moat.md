# ADR-0002：超越靠"产品化 + 开源/TCO 结构性护城河"，CXL 作期权

- 状态：已接受（v4）
- 日期：2026-09

## 背景

需回答"Proxmox 如何超越 VMware"。v3 押在"CXL 原生分层"作最硬技术超越点。核验发现：① CXL 在 KVM
guest 上的 TPP/DAMON 开销与精度无实测来源；② CXL 扩展器 $/GB ≥ DIMM，DRAM 涨价同样抬高它，成本论
不成立；③ VMware Tier0/Tier1 架构可纳入 CXL（trade press 已列候选 [18]），非结构不可跟随；④ "骑内核
上游"是所有 KVM 同类共享，对同类零差异。

## 决策

超越 = **把内核已有主动机制产品化**（快速补产品化差距）+ 在 VMware **结构上无法复制的两条**上取胜：
**开源/AGPL（可审计、可 fork、无锁定）**与**无按核授权 TCO**。**CXL 作随内核成熟推进的期权与时机
领先**，不作近期主打，也不作结构性超越论据。

## 备选

1. v3 的"换战场到 CXL"——被上述四点削弱。
2. 纯打价格战——价格是最可逆杠杆（对手可给留存折扣），不可持续。

## 后果

- 近期主打难民 + CSP（CSP 为 CXL 期权首用买家）；信创限定（见 ADR 与报告 §七）。
- 护城河叙事收敛为"开源无锁定 + 无按核 TCO"，其余按可跟随处理。
- why-now 只挂 NVMe/现有通路（Broadcom 迁移 + DRAM 涨价）。
